Перманент

Матрицы — это фундаментальный инструмент линейной алгебры. Они используются для решения систем уравнений, преобразований пространства и многих других задач. У матриц так же имеются свои характеристики, например определитель. В данной работе будет рассматриваться свойство, похожее на определитель, которое называется перманентом.

1. Определение матрицы и перманента

Матрица - таблица из m строк и n столбцов.

Пример матрицы размера 3 × 3:

[
123
456
789
]

Перманентом называют сумму по всем различным перестановкам произведений всех элементов взятых по одному из каждого столбца и из каждой строки. В отличии от определителя, при подсчёте не используется чётность перестановки. Перманент над квадратными матрицами обозначается как per(A), а в общем случае Per(A). Так например выглядит нахождение перманента для матрицы 2х2:

[
ab
cd
 ]
per(A) = ad + bc
Общая формула перманента:
per(A) = ∑ σ ∈ Sn ∏ n i=1 ai,σ(i)
где Sn — множество всех перестановок чисел {1, 2, ..., n}, σ(i) - функция, которая ставит в соответствии i строке некоторый столбец σ(i), n - размер матрицы.

2. Формулы

Для подсчёта перманента можно использовать разные методы вычисления. Результат получится один, но сложность формулы может быть разной. Для особых типов матриц тоже существуют свои формулы вычисления перманента. Здесь представлены основные методы для всех типов матриц.

Формула перманента основанный на методе включение исключения:
per(A) = ∑ S ⊆ {1, …, n} ( − 1 ) n − |S| ∏ n i=1 ∑ j ∈ S aij,
Обозначения: S - множество всех перестановок, n - размер матриц, aᵢⱼ - элемент матрицы с индексами i j.
Формула Глисона для перманента:
per(A) = 1 / 2 n−1 ∑ δ ∈ B ( ∏ n k=1 δk ) ∏ n i=1 ∑ n j=1 δj aij
Обозначения: B = {0, 1}n — множество всех бинарных векторов длины n, δ = (δ₁, δ₂, …, δₙ), где каждое δk ∈ {-1, 1}, aᵢⱼ - элемент матрицы с индексами i j.
Формула Лапласа (разложение по i-й строке):
per(A) = ∑ n t=1 ait · per(A(i | t))
Обозначения: A(i | t) — матрица, полученная из A вычёркиванием i-й строки и t-го столбца

3. Пример нахождения

[
123
456
789
]
Воспользуемся методом Лапласа, разложим матрицу по первой строке, получим 3 матрицы меньшей размерности:
[
56
89
 ] [
46
79
 ] [
45
68
 ]

Найдём их перманенты, с помощью формулы для матриц размера 2х2, указанной выше:
per(первая) = 93;
per(вторая) = 78;
per(третья) = 62;
Далее умножим на соответствующий элемент, по которому разлагали матрицу и просуммируем:

per(A) = 1 * per(первая) + 2 * per(вторая) + 3 * per(третья) = 1 * 93 + 2 * 78 + 3 * 62 = 435
